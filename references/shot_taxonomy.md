# 画面槽位分类词典

M4 生成 shotlist.md 时，按此词典查表确定每个品类的画面构成。

## 槽位规则

### 固定核心槽位（6 张，所有品类强制出图）

| 槽位 | 名称 | 用途 | 带 UI | render_mode |
|------|------|------|------|-------------|
| S1 | 主视觉 KV | 传达世界观+核心卖点，海报级别 | ❌ | `concept_allowed` |
| S2 | 标志性场景图 | 游戏内代表性场景/世界观大图 | ❌ | `concept_allowed` |
| S3 | 主界面 | 进游戏第一眼，气质+功能入口 | ✅ | `mobile_screenshot` |
| S4 | 战斗 / 核心玩法画面 | 核心循环最高频画面 | ✅ | `mobile_screenshot` |
| S5 | Boss战 / 高潮场景 | 玩法上限和爽感天花板 | ✅ | `mobile_screenshot` |
| S6 | 角色养成 / 成长系统 | 长线留存的可视化锚点 | ✅ | `mobile_screenshot` |

> 原方案的「KV ×2」调整为「主视觉 KV（S1）+ 标志性场景图（S2）」，避免双 KV 冗余，同时保证世界观传达。

### 品类替换槽位（2-3 张，按品类查表补充）

根据项目所属品类，从下方品类映射表中选择 2-3 张替换画面。每张替换画面默认 `mobile_screenshot`（除非是宣传合影）。

### 可选槽位：系统与社交界面（默认不出）

仅当品类标签命中以下任一标签时启用：
- `MMORPG` / `社交模拟` / `恋爱` / `休闲（家园/装扮向）`
- 其他社交驱动型品类

启用后追加 1 张「系统与社交界面」画面（`mobile_screenshot`）。

### 总数约束

- 最少：6 张（6 固定核心）
- 最多：10 张（6 固定 + 3 品类替换 + 1 可选社交）

## 使用方式

LLM 在 M4 步骤 3 生成 shotlist.md 时：

1. 先写入 6 张固定核心槽位（S1-S6）
2. 根据项目所属品类，在品类映射表中查找替换槽位，补充 2-3 张（槽位编号 S7-S9）
3. 判断是否需要启用社交槽位（S10）
4. 最终 shotlist 编号为 S1-S{6+替换数+可选数}

## 扩展规则

新增品类时，仅需在品类映射表中增补一行，无需改动主流程。
